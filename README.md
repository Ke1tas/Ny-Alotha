# Лабораторная работа 3
Я изменил программу на C++, которая загружает квадратные матрицы из файлов, перемножает их, сохраняет результат, добавив распараллеливание с помощью MPI, а так же болчное умножение для лучшей работы кэша процессора.
Скрипт `matrix_mul_mpi.py` отвечает за создание матриц, работу с директориями, запуск программы на C++, вывод её результатов работы и визуализацию.
# Запуск программы
Ввести `python3 matrix_mul_mpi.py` в терминал.
