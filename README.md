# Лабораторная работа 5
Я запустил на суперкомпьютере "Сергей Королев" программу, которая загружает квадратные матрицы из файлов, перемножает их, сохраняет результат, с распараллеливанием с помощью MPI
Скрипт `matrix_mul_mpi.py` отвечает за создание матриц, работу с директориями, запуск программы на C++, вывод её результатов работы и визуализацию.
