# Лабораторная работа 2
Я изменил программу на C++, которая загружает квадратные матрицы из файлов, перемножает их, сохраняет результат, добавив распараллеливание с помощью openMP.
Скрипт `matrix_mul_omp.py` отвечает за создание матриц, работу с директориями, запуск программы на C++, вывод её результатов работы и визуализацию.
# Запуск программы
Ввести `python3 matrix_mul_omp.py` в терминал.
# Результаты исследования
